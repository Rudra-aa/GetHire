# Smart Interviewer PRD

## Problem Statement

Students and job seekers struggle to prepare for technical interviews with realistic feedback.

Current interview preparation platforms provide static questions and generic scoring.

There is a need for an intelligent interview platform that provides personalized interviews and actionable feedback.

## Target Users

1. College Students
2. Fresh Graduates
3. Job Seekers
4. Placement Training Institutes

## User Journey

Step 1:
Upload Resume

Step 2:
System Extracts Skills

Step 3:
AI Generates Questions

Step 4:
Interview Begins

Step 5:
Candidate Answers

Step 6:
Emotion Analysis Runs

Step 7:
AI Evaluates Answers

Step 8:
Report Generated

## Functional Requirements

FR-1 Resume Upload

FR-2 Resume Parsing

FR-3 Skill Extraction

FR-4 AI Question Generation

FR-5 Interview Session Management

FR-6 Candidate Answer Storage

FR-7 Answer Evaluation

FR-8 Face Emotion Detection

FR-9 Voice Emotion Detection

FR-10 Confidence Scoring

FR-11 Final Recommendation

FR-12 PDF Report Generation

## Success Metrics

- Interview Completion Rate
- User Satisfaction Score
- Evaluation Accuracy
- Report Generation Success Rate
- Model Response Time
